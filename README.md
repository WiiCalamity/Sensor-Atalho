# Sensor-Atalho
Sensor Atalho é um projeto de microcontrolador que tem como objetivo proteger a privacidade do usuário.  

### Como funciona
O Sensor Atalho é um microcontrolador com sensor que fica grudado em uma porta.  
Assim que o microcontrolador detectar algum movimento da porta, ele dispara um sinal no computador que escurece a tela ou desliga o microfone do usuário.
